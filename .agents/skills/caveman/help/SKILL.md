# Caveman Command Manual

## Commands

- `/caveman` : Activate default caveman mode (full intensity).
- `/caveman lite` : Switch to Lite intensity (tight, professional, full grammar).
- `/caveman full` : Switch to Full intensity (standard caveman, no articles, fragments).
- `/caveman ultra` : Switch to Ultra intensity (maximum abbreviations, causality arrows).
- `/caveman off` : Return to standard conversational AI mode.
- `/caveman commit` : Generate conventional commit message from git diff.
- `/caveman compress` : Compress logs or text into minimal token representation.
- `/caveman review` : Review diff or file for bugs with zero conversational filler.

- All technical facts, file paths, commands, and code logic remain 100% exact.
